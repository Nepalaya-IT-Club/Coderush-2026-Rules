## 🚀 Quick Start for Teams

1. Read [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) — know the event rules before you start.
2. Create your team repository under this GitHub organization, following the naming format in [`GITHUB_WORKFLOW.md`](./GITHUB_WORKFLOW.md):
   ```
   team-name-coderush2026
   ```
3. Add all team members as collaborators, **and add the Nepalaya IT Club GitHub org/account as a collaborator too** so organizers and judges can review your work.
4. Follow the branching and commit rules in [`GITHUB_WORKFLOW.md`](./GITHUB_WORKFLOW.md) throughout the event.
5. Structure your project's `README.md` using [`README_TEMPLATE.md`](./README_TEMPLATE.md).
6. Before the deadline, go through [`SUBMISSION_CHECKLIST.md`](./SUBMISSION_CHECKLIST.md) and submit your repo link through the official submission form.
7. Fill out [`AGREEMENT.md`](./AGREEMENT.md) with your team details and signatures, and hand a copy to the organizing team.
