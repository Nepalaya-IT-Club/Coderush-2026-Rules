# Submission Checklist

Before the submission deadline, make sure your team has completed everything below.

## Repository

- [ ] Repository is named `team-name-coderush2026`
- [ ] Repository visibility is set to **Public**
- [ ] All team members are added as collaborators
- [ ] Nepalaya IT Club GitHub org/account is added as a collaborator
- [ ] Final working version is merged into `main`
- [ ] No commits will be made after the deadline

## Code Quality

- [ ] Code runs without errors after following your own setup instructions
- [ ] No unused/dead code left in the final submission
- [ ] Sensitive keys/secrets are NOT committed (use `.env` + `.gitignore`)

## Documentation

- [ ] `README.md` follows the [README Template](./README_TEMPLATE.md)
- [ ] Team information and GitHub usernames are correct
- [ ] Setup/installation steps are tested and accurate
- [ ] A live demo or video demo is prepared to present the project

## Final Steps

- [ ] GitHub repository link submitted through the official submission form
- [ ] Team has reviewed the [Code of Conduct](./CODE_OF_CONDUCT.md) one final time
- [ ] Team's signed [Agreement](./AGREEMENT.md) handed to an organizer
